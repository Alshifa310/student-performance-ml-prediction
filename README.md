
# 🎓 Student Performance ML Prediction

This project applies machine learning techniques to analyze and predict student performance based on various academic and behavioral factors. The dataset includes features such as study time, past failures, absences, and health conditions. The end goal is to uncover what factors most influence student success and build models that can predict outcomes.

## 📁 Repository Contents

- `Data_Preprocessing_and_Exploration.ipynb`:  
  Covers loading the dataset, handling missing values, encoding categorical features, feature correlation analysis, and data visualization.
  
- `Model_Training_and_Evaluation.ipynb`:  
  Includes train-test split, model selection, accuracy analysis, confusion matrix visualization, and comparison of various classification models.

- `StudentPerformanceFactors.csv`:  
  Raw dataset used for training and evaluation.

## 💻 Technologies & Tools

- **Python 3**
- **Jupyter Notebook**
- **Pandas** & **NumPy** – data manipulation
- **Matplotlib** & **Seaborn** – visualization
- **Scikit-learn** – ML algorithms and model evaluation
- **Machine Learning Algorithms**:
  - Logistic Regression
  - Linear Regression
  - Decision Tree
  - K-Nearest Neighbors (KNN)
  - Random Forest Classifier

## 🚀 Project Highlights

- End-to-end ML pipeline implementation

## 📊 Dataset Overview

The dataset includes academic and socio-behavioral data collected from secondary school students. Each record includes multiple input features and the target label indicating pass/fail performance.

> **Note**: The dataset is provided for academic purposes.
